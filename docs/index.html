wattif

Ask what-if of your own ride data.

A local command-line tool that reads the FIT files from your Garmin and answers two questions most cycling tools skip, both without a power meter.

Source on GitHub Install

Am I actually getting fitter?

Not raw average speed, which wind and terrain drown out, but speed per heartbeat, corrected for wind, gradient and equipment. A fast day into a tailwind stops looking like progress, and a hard slog into a headwind stops looking like decline.

What would make me faster?

Tyres, riding position, a different bike, fewer stops. Measured against your own rides rather than a generic calculator.

Within-ride A/B tests work today. The ranked what-if table is still to come.

How it works

Both answers come out of the same physics: estimate power from speed, gradient and air density, correct every ride for the wind you actually rode through, then compare like with like.

Test a change inside one ride

Whole-ride comparisons are a poor way to judge equipment. Speed per heartbeat scatters around 5% from ride to ride, so a 4% change needs roughly sixteen rides per arm before it clears the noise, by which time the seasons have moved underneath the experiment.

wattif ab puts both arms inside the same ride instead. Set the watch to auto-lap every 5 km, switch setup at every beep and change nothing else. Weather, fitness and route are then identical on both sides of the comparison.

  • The opening of each block is discarded, because heart rate lags a change in position or effort by a minute or more.
  • Each block is compared against the mean of its two neighbours, which cancels drift across the ride exactly.
  • Blocks are cut by distance, not time: on 18 real rides the scatter was 3.4% with 5 km laps, against 5.1% with 15-minute and 12.6% with 5-minute blocks.

Private by design

No server, no account, no telemetry. Your rides stay on your machine. The only thing that leaves it is a coarsened coordinate for a historical weather lookup, and that is cacheable and optional. Heart rate is health data, which is why this stays a local tool rather than a hosted one.

Your Garmin password is used once to obtain tokens and is never written to disk. Garmin has no personal API, so wattif sync speaks to the same private endpoints their phone app uses. That has broken before, so the official Garmin export ZIP always works as a fallback.

Install

Python 3.11 or newer.

$ git clone https://github.com/jakubwaller/wattif.git && cd wattif
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -e .
$ cp config/profile.example.yaml config/profile.yaml   # then edit it

$ wattif sync                       # pull recent rides from Garmin Connect
$ wattif import ~/Downloads/x.zip   # or import a Garmin bulk export
$ wattif analyse --min-km 20        # corrected trend, quarter by quarter
